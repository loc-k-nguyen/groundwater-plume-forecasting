# Contributing

Use a branch and a focused pull request. Describe the change and its verification. Run the CPU checks in REPRODUCE.md. Do not commit raw fields, checkpoints, caches, simulator material, credentials or generated outputs.

Preserve scientific identifiers, fixed splits, archived numerical sources and limitations. Changes to a model or protocol must be documented as new research; they must not replace the paper's recorded results. Keep manuscript versions separate from software release versions.

Report suspected numerical or provenance errors with the relevant artifact identifier, source hash and a minimal reproduction. Do not include restricted assets in an issue or pull request.
