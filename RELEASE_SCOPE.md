# Release scope

This paper-scoped release contains ML code, evaluation/statistics/figure scripts and lightweight CSV/JSON summaries. The original source package is preserved, and this repository has standalone release history rather than the full research-project history.

Included: the paper's TA-ANP family and comparison model implementations, representative configurations, scientific identifiers, fixed splits, normalization, numerical summaries, restricted-input-independent checks, and material pairing, screening, failed-run and conductivity-twin provenance.

Excluded: raw or processed field arrays, simulator setups or invocation commands, executables, checkpoints, full prediction caches, credentials, personal machine paths, private infrastructure, manuscript drafts, reviewer correspondence, internal planning, agent configuration, unrelated objectives and later extensions. Field-bearing figure panels are excluded; only aggregate plots are included.

The owner authorized MIT distribution and public release of this code-only scope on October 15, 2026. Retained third-party notices remain applicable. Version acml-v15-2026-10-15-r1 maps to the current local v15 article and Supplementary; publication metadata and the actual portal upload remain separate author records. No DOI, collaborator access or hosted forecasting service is implied. Future changes require a new software version and must preserve the paper-corresponding tag.
