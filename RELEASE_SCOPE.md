# Release scope

This is a private, paper-scoped preparation snapshot. The allowed release scope is ML code, evaluation/statistics/figure scripts and lightweight CSV/JSON summaries. The source package is preserved, and the new repository starts with fresh Git history.

Included: the paper's TA-ANP family and comparison model implementations, representative configurations, scientific identifiers, fixed splits, normalization, numerical summaries, restricted-input-independent checks, and material pairing, screening, failed-run and conductivity-twin provenance.

Excluded: raw or processed field arrays, simulator setups or invocation commands, executables, checkpoints, full prediction caches, credentials, personal machine paths, private infrastructure, manuscript drafts, reviewer correspondence, internal planning, agent configuration, unrelated objectives and later extensions. Field-bearing figure panels are excluded; only aggregate plots are included.

Public release still requires author/owner confirmation of copyright, any third-party origins and license scope, approval of the final manuscript/code mapping, complete sensitive-content review, and an explicit visibility change request. No collaborators, tag, GitHub Release, DOI or public deployment is created here. A private URL is inaccessible to employers and reviewers without separately granted access.
